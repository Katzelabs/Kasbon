# KASBON Brand

Unlike the rest of `docs/`, this file is **current**, not historical. The
artwork it describes is generated by `brand/generate.py`; see `brand/README.md`
to rebuild it.

## The idea

*Kasbon* is two things at once. It is the product — Kasir Bisnis Online — and it
is the word an Indonesian shop owner already uses for the slip of paper that
records what someone owes. The app exists to replace that slip.

So the mark is a geometric **K** whose stem is a receipt torn off at the foot.

The tear is small on purpose. The mark had to survive a 16px favicon, and a
receipt silhouette does not — at that size it collapses into a white blob. A
letterform does. So the letter carries the legibility and the tear carries the
meaning, and the tear is the part allowed to disappear: it is texture on a phone
home screen, a story at hero size, and gone by the time it would have turned to
mush. The upper arm rises past the stem's shoulder, which is the only nod the
mark makes to the profit tracking the product is built around.

## Colour

The mark takes its palette straight from `AppColors` — no brand-only colours
exist, and none should be added.

| Role | Value | Token |
|---|---|---|
| Gradient start | `#3B82F6` | `AppColors.primaryHover` |
| Gradient end | `#1D4ED8` | `AppColors.primaryDark` |
| Flat / one-colour | `#2563EB` | `AppColors.primary` |
| Knockout on the tile | `#FFFFFF` | `AppColors.onPrimary` |

The gradient runs top-left to bottom-right and is available in Dart as
`AppGradients.brandMark`. **It is not `AppGradients.primaryCard`** — that one
runs blue to purple, and a logo tile drawn with it would not match any icon the
app ships. `primaryCard` is for summary cards; leave it there.

## The assets

| Want | Use |
|---|---|
| An app tile, at any size | `KasbonLogoTile` (Dart) / `kasbon-icon.svg` |
| The glyph alone, tintable | `KasbonMark` (Dart) / `kasbon-mark.svg` |
| Mark + wordmark, side by side | `brand/kasbon-logo-horizontal.svg` |
| Mark + wordmark, centred | `brand/kasbon-logo-stacked.svg` |
| The word alone | `brand/kasbon-wordmark.svg` |

The wordmark is Plus Jakarta Sans ExtraBold, tracked +0.09em, **converted to
outlines**. Never re-set it as live text: a logo that references a font by name
is one missing font away from rendering as Times New Roman.

## Rules

**Clear space** — keep a margin of at least a quarter of the mark's height clear
on all four sides. The generated lockups already exceed this.

**Minimum sizes**

| Asset | Floor |
|---|---|
| Mark alone | 16px |
| Stacked lockup | 96px wide |
| Horizontal lockup | 120px wide |

Below the lockup floors the wordmark stops being readable — use the mark alone
instead of shrinking further.

**Don't**

- Recolour the mark outside the table above, or put the gradient on the glyph
  instead of the tile.
- Redraw, re-space, outline, or add effects to the glyph. Need it bigger? It is
  a vector and a `CustomPainter`; both scale.
- Stretch it. Sizing is by **height** — the mark is taller than it is wide
  (72.5 : 87), and driving it from width makes it tower out of its container.
- Set the mark on a mid-blue ground where the tile stops separating. On colour,
  use `kasbon-mark-white.svg` with no tile.
- Reintroduce a stock Material icon as a stand-in. `Icons.point_of_sale_rounded`
  held this slot before the mark existed; it should not come back.

## Using it in the app

```dart
import 'package:kasbon_pos/shared/brand/kasbon_mark.dart';

KasbonLogoTile(size: 72)              // the icon, glow on — auth screens
const KasbonLogoTile(size: 80, glow: false)   // dense surfaces — About
KasbonMark(size: 24, color: AppColors.primary) // the glyph alone
```

Both are drawn, not bundled — a `CustomPainter` over the same coordinates the
icon generator uses. That keeps the mark crisp at any size and tintable without
adding an SVG dependency or a PNG ladder to the app bundle.

The mark is therefore drawn in two places, and they have to agree:
`brand/geometry.py` and `app/lib/shared/brand/kasbon_mark.dart`. Change one,
change the other, and re-run the generator.
